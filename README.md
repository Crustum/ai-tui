# CakePHP AiTui Plugin

The **AiTui** plugin provides a terminal chat screen for interacting with AI agents from CakePHP console applications.

Use it to stream agent answers token by token, render tool invocations inline, run slash commands with selection panels, recall inputs with history, queue messages submitted mid-turn, and persist conversations through the driver store while turns run through `Crustum\AiInteraction` contracts.

## Requirements

* PHP 8.4+
* crustum/cakephp-ai
* crustum/ai-interaction

See [Versions.md](docs/Versions.md) for the supported CakePHP versions.
